# 0009 — M5 migrate + coexist: a SOFT, per-use-case `phasing` ↔ `phasing-flow` coexistence pointer (à-la-carte-by-primitive; deprecate-or-keep deferred per-use-case), NOT a wholesale deprecation; count-neutral + no version bump

- **Status:** accepted
- **Date:** 2026-06-09
- **Decision:** M5 (the LAST milestone of the phasing-flow initiative) makes the `phasing` and `phasing-flow` skills **coexist** via a **SOFT, per-use-case "prefer `phasing-flow` for X / keep `phasing` for Y" routing pointer** — explicitly **NOT a wholesale deprecation of `phasing`**. The pointer is grounded in a use-case routing map (UC-1..UC-10): **only UC-1** (a multi-subsystem **code** build where a real deterministic verifier exists) clearly prefers `phasing-flow`; **UC-6** (the user-owned offline `run.json` state model) is "either"; **UC-2..5 and UC-7..10** all **stay on `phasing`** — cross-session re-grounding in a genuinely fresh OS session (UC-2), a human gate at *every* transition with no subagents (UC-3), multi-terminal/parallel attended phase sessions (UC-4), GitHub-issue-per-phase tracking (UC-5), crash/poll-drop recovery of a long-lived orchestrator (UC-7), mid-flight checkpoint/resume (UC-8), in-run self-evolution (UC-9), and non-code/judgment-shaped work where the engine fail-CLOSED-aborts on a prose spec (UC-10, the direct ADR-0007 finding). The coexistence model is **à-la-carte-by-primitive**: `phasing-flow` deliberately ports none of `phasing`'s machinery, and each tool keeps what it is best at. Any actual per-use-case deprecation is **deferred to after migration** — M5 routes, it does not remove. M5 is one ordered, **additive** edit-set across docs + governance: it **deletes nothing** (the `phasing` skill, all 10 `phase*` commands, 7 references, 2 evals, 3 scripts survive intact), **bumps no version** (plugin stays v2.1.0), **ripples no counts** (13 skills / 17 commands / 9 hooks unchanged), and **adds no CI job** (CI stays 21 — M5 ships no testable seed/kernel, only prose + governance).
- **Context:** Impact-matrix **Theme 6** ("phasing coexistence") is the M5 scope; the design (§2/§8/§12 + §14) reframed M5 from a wholesale `phasing` deprecation to coexistence (CHANGELOG `[Unreleased]` M0 `### Docs` already recorded this reframe). M0→M4 are all merged to `main` (PR #52 `d3d27ee`, PR #53 `732b729`). The work was dogfooded `/phasing-flow plan`-style on branch `feature/m5-migrate-coexist` off `origin/main` (`732b729`): a 5-reader **Understand** workflow (`wf_ecff6f1d-e27`) mapped the 10 phasing use-cases, mapped `phasing-flow`'s coverage to keep the pointer honest, and **verified the Theme-6 ripple surface against the live tree** — its completeness critic OVERRODE the matrix by catching **6 narrative surfaces Theme 6 missed** (the consumer cheatsheet template — highest leverage — plus `llms.txt` template, `docs/methodology.md` §E, `docs/philosophy.md`, `specs/07` §D, `specs/02` prose), **2 ghosts to drop** (the `.claude/phasing/2026-05-04-*` run-state dir does not exist; `onboarding/day-1.md` has no phasing ref since its 2026-06-05 rewrite), and **1 already-satisfied item** (`.gitignore`). The live **planning-brain** seed (`wf_9e261b09-62c`, `ground:false`) synthesized one master plan whose adversarial critic caught a **double count-coupling** (`specs/02-templates.md` `(8)` enumeration duplicates the cheatsheet self-count) and forced a single canonical ADR slug (lychee runs `--offline` and flags a wrong intra-repo link). Per **gate-on-decisions**, the three diff-moving choices (narrative-retarget scope, the `[local]` `~/.claude/CLAUDE.md` retarget, the design-spec banners) went to a human GATE 2; the version/count and ADR-framing items were locked confirm-only.

- **Alternatives considered:**
  - **Wholesale-deprecate `phasing` (mark it for removal, route everything to `phasing-flow`).** Rejected — `phasing` wins UC-2..UC-5 and UC-7..UC-10 (fresh-OS-session re-grounding, human-gate-every-transition with no subagents, multi-terminal/parallel attended sessions, GitHub-issue-per-phase tracking, crash/checkpoint recovery, non-code/judgment work where the `phasing-flow` engine fail-CLOSED-aborts on a prose spec per ADR 0007). The à-la-carte-by-primitive model keeps each tool at what it is best at; this is the **only** permitted use of the word "deprecated" in the M5 prose surface.
  - **Ship the routing pointer as a `### When phasing vs phasing-flow` `##` section in the SKILL.** Rejected — the live `phasing/SKILL.md` jumps from the intro straight to `## §4` with no §1–§3, so a new H2 would sit out-of-sequence and break the section taxonomy. A blockquote callout carries the pointer with zero heading-numbering incoherence.
  - **Banner the `docs/audit/*` files as "superseded".** Rejected — reading the bodies, several catalog an external framework or critique spec quality and remain largely valid; "superseded" over-claims staleness and contradicts "phasing survives". "Historical snapshot" is the honest framing.
  - **Bump the plugin version / file a `### Deprecated` changelog block.** Rejected — M5 is shape-neutral (no new/removed skill/command/hook/workflow/spec; M4 precedent shipped strictly more surface and did not bump), so spec-08's MINOR/MAJOR bump triggers do not fire; and a soft per-use-case pointer with `phasing` fully retained is a `### Changed`, not a "marked for removal" `### Deprecated`. The per-use-case deprecation rule (`### Deprecated` + ADR) binds *later*, if/when a specific use-case is actually deprecated.
  - **Scope the narrative sweep to the Theme-6-confirmed 6 sites only.** Rejected at GATE 2 — the completeness critic's 6 gaps include the consumer cheatsheet (the most-seen daily-command surface); skipping them leaves the stalest, highest-traffic docs and would split mirror sections (`specs/07` §D from `docs/methodology.md` §E).
- **Supersedes / superseded by:** none. Closes the phasing-flow initiative (M0→M5). Builds on **ADR 0007** (the UC-10 prose-spec fail-CLOSED finding that grounds "keep phasing for non-code work"), **ADR 0005/0006** (the à-la-carte-by-primitive adoption precedent), and **ADR 0003/0002** (the seed scriptPath + consensus contracts the M5 dogfood loop ran on). Implements impact-matrix **Theme 6** and design §8/§12 (M5).
