# 0005 — The integrate-branch Phase-2 audit seed: reduce-parity acceptance, copy-3-libs, consensus dedup-only for distinct lenses, a synthetic-tsc D2 fallback, and transitive engine adoption

- **Status:** accepted
- **Date:** 2026-06-06
- **Decision:** M3 adoption (skill 1 of 3) re-platforms `integrate-branch`'s **Phase-2 audit only** onto the **fourth committed Workflow seed** under the ADR 0003 scriptPath contract (after `iterative-review`, `planning-brain`, and the `phasing-flow` engine). Ten sub-decisions, all resolved by the human at the GATE-2 plan gate (planning-brain run `wf_0b27698d-8a8`): **(a)** a committed **SEED**, not an inline `parallel()` — only a seed makes the verdict-parity guard + RED self-test a CI-enforceable `node --test` [OD5]; **(b)** **COPY exactly 3 libs** (`canonical`, `consensus-aggregate`, `verifier-detect`) held byte-identical to the `iterative-review` originals by a CI diff-guard — NOT the engine's 7-lib set (a verbatim 7-lib clone would FAIL CI: the other 4 don't exist here); **(c)** acceptance is **reduce-parity, two-gate** — Gate A (a fixture where consensus + resolveVerifier are inert ⇒ byte-identical composite + route to an independent `legacyReduce`) + Gate B (documented deltas vs pre-registered goldens) — because literal byte-identity to the *current* audit is unachievable (it is prose; consensus + resolveVerifier change D4/D2 by design) [OD1]; **(d)** D4 consensus runs at **`critVotes=1` (dedup-only)** for the 6 semantically-distinct `pr-review-toolkit` lenses — `critVotes=2` (tuned for shared-lens reviewers that co-locate) would demote nearly every D4 critical and gut the signal [OD2]; **(e)** the D6-omitted renormalization is **÷0.95** and the route matrix compares the **raw float** composite (display rounds half-up) [OD3]; **(f)** D2 is **`resolveVerifier` + a synthetic `npx tsc --noEmit` fallback** when a `tsconfig.json` exists but no `typecheck` script emitted a tsc command — closing the silent type-check-gate hole de-hardwiring would otherwise open [OD4]; **(g)** the blocking overrides **FAIL CLOSED** (Discard > Rebuild precedence) and are computed in the **authoritative reduce** on deterministic signals, never in the fail-open agent layer; **(h)** **no `fixed-point` guard** — a one-shot audit fan-out has no cursor to stall, so ADR 0004's deferred stall guard lands in M3 #2 (`/work-issue`), not here; **(i)** engine adoption is **transitive** via `/work-issue` and is a Phase-4 **NO-OP for this PR** (the handoff already names `/work-issue`; engine-backing becomes real only after M3 #2 — the PR must NOT claim end-to-end engine-backed salvage); **(j)** the **Phase-3 route gate and Phase-4 salvage/rebuild/discard handoffs stay BYTE-VERBATIM**, guarded by a content-anchored frozen-region test; the rewire is **additive + revert-clean** (revert = delete `workflow/` + one SKILL pointer block; the D1–D6 prose remains the fallback).
- **Context:** M3 wires `work-issue` / `spec-it` / `integrate-branch` onto the framework; integrate-branch is first (cleanest, self-contained audit→`parallel()` transform; it builds the `resolveVerifier` + consensus plumbing work-issue then inherits). The planning brain + its **adversarial critic** caught five factual errors the three scout proposals shared, each re-verified against the working tree: **(1)** `consensus-aggregate.mjs` returns a deduped **ARRAY**, not counts (`:89`) — the glue must derive both crit AND imp counts; **(2)** each consensus demotion is **+6 net, not +10** (a demoted critical leaves the −10 term and enters the −4 term); **(3)** 6 distinct lenses × `critVotes=2` demotes nearly all D4 criticals (→ OD2); **(4)** canonical dedup keys on the normalized **description**, so distinct-description findings at one line do not collapse; **(5)** the 6 named `pr-review-toolkit` agentTypes were **unproven** inside `agent()` (M1/M2 used only the generic lenses) — so a cheap **front-loaded agent-resolution probe** (run `wf_8bf0957a-0cc`) confirmed all three sampled agentTypes resolve AND emit findings with a populated integer `line` BEFORE the full build; and **(6)** the existing engine CI `cmp` loop iterates 7 libs — the new harness must iterate exactly the 3 copied here.
- **Consequences:**
  - Seed at `plugins/unifylabs-workflow/skills/integrate-branch/workflow/`: `compute-audit.mjs` (pure, import-free authoritative reduce — every SKILL.md formula verbatim + composite + ÷0.95 renorm + raw-float route + FAIL-CLOSED overrides) + `audit-aggregate.mjs` (the agent→reduce bridge: D4 consensus + naive reference + D2 role-tagging with the synthetic-tsc fallback; imports 2 copied libs) + `src/audit-glue.mjs` (the typed `parallel()` over the 6 dimensions, D4 nesting `parallel(6 reviewers)`, the only runtime-touching file) + 3 copied `lib/` modules + cloned `build-workflow.mjs` / `check-bundle.mjs` + the committed `integrate-audit.workflow.mjs` bundle.
  - **44 zero-dep `node:test` cases**, red-capable: `compute-audit` (23 — formulas, floors, ÷0.95 all-100⇒100 on both paths, raw-float boundaries, override precedence), `audit-aggregate` (12 — consensus dedup, unlocatable-critical demotion, D2 role-tag + synthetic fallback), `verdict-parity` (6 — Gate A byte-identity, Gate B deltas, discrimination), `frozen-regions` (3 — Phase-3/4 byte-identity + the additive pointer present). A new **`integrate-audit-harness`** CI job runs `node --check`, `node --test`, the **3-copied-lib** byte-identity guard, bundle parity + `check-bundle` + import-free, and a RED self-test (mutate a `compute-audit` weight ⇒ the suite must turn red).
  - The seed returns `{ scores, composite, composite_display, route, route_basis, override, degraded, signals }` with **no mid-run gate**. A `degraded` result (a null from an override-carrying dimension D1/D2/D5) never auto-recommends Salvage (downgraded to *user-decides*) and treats its `override_signals` as potentially-firing — fail-closed.
  - **Front-loaded probe `wf_8bf0957a-0cc`** (`code-reviewer`, `silent-failure-hunter`, `type-design-analyzer`): all returned non-null structured findings with populated integer lines at the planted-defect locations.
  - **End-to-end smoke `wf_026d5240-bce`** (the committed bundle via scriptPath over a real diff — the kit's own `HEAD~1...HEAD`): the bundle executed in the Workflow VM; all 6 dimensions ran (D4's 6 `pr-review-toolkit` reviewers resolved → 7 consensus-deduped importants, 0 criticals), D6 not-applicable was renormalized ÷0.95, composite **88.37** (the exact renorm of the per-dimension scores `(30+20+9.75+7.2+17)/0.95`) → route **salvage**, no overrides, not degraded. 12 agents.
- **Alternatives considered:**
  - **Inline `parallel()` authored at runtime.** Rejected — forfeits the CI-enforceable verdict-parity guard + RED self-test that the M3 acceptance criterion requires.
  - **`critVotes=2` (literal consensus).** Rejected — tuned for shared-lens reviewers; over 6 distinct lenses it demotes nearly all D4 criticals (a silent signal regression). `critVotes=1` still adopts the lib (same code path + dedup).
  - **Accept the D2 tsc-gate weakening.** Rejected — the synthetic `npx tsc --noEmit` fallback (OD4) preserves the −30 gate on real-world JS projects lacking a `typecheck` script.
  - **Literal byte-identity acceptance vs the current audit.** Rejected as unachievable (prose reference; consensus/resolveVerifier change behavior by design). Reduce-parity over a frozen fixture is the only honest CI-enforceable formulation.
  - **Cross-seed import of the shared `lib/`.** Rejected (ADR 0003) — breaks the self-contained-seed invariant. Copy + a CI byte-identity diff-guard instead.
